## User Role & Access Manager

An advanced WordPress plugin built using object-oriented PHP
to manage custom user roles via the admin dashboard.

### Highlights
- Loader-based architecture
- Clean separation of concerns
- Secure form handling with nonces
- Uses WordPress Roles API

### Stack
- PHP (OOP)
- WordPress Hooks & APIs
- Git

### Purpose
Designed to demonstrate professional WordPress plugin
development suitable for open-source contribution and
engineering interviews.
